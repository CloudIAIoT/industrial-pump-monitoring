# Industrial-pump-monitoring

Let’s imagine an industrial facility that uses three centrifugal pumps to transport water in a recirculation system.
The pumps operate independently and are equipped with sensors that allow their performance to be monitored.
Currently, the facility does not have a centralized system that allows users to view historical measurements and monitor the status of the equipment remotely.
Our project proposes implementing a monitoring system that collects this information and makes it accessible through an Azure-managed infrastructure.
